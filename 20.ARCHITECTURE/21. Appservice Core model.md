> **Vision**: 기획-생산-마케팅-판매-고객 피드백까지, 상품의 전체 생애주기(End-to-End)를 AI 알고리즘과 유관부서 협업으로 자동화하는 **스마트 커머스 OS**.

> **2차 프로젝트 스코프 노트** ([[02. Project WBS & Roadmap]] Phase 16 참고): 아래 3대 엔진 중 ①ML 수요예측/자동발주, ②RAG 코파일럿(Teams 봇 기반 부서간 협의로 재정의)만 2차 MVP로 구현. ③GenAI 마케팅 콘텐츠 생성(카피라이팅·룩북 이미지)은 이번 스코프에서 제외하고 향후 로드맵으로 유보.

### 🤖 1. AI 핵심 엔진 3대 요소

#### ① ML 기반 수요 예측 & 원가/재고 최적화 (Predictive ML Engine)
* **수요 예측 (Demand Forecasting)**: 
  * 지그재그 내 검색 트렌드, 과거 3년간 체형별/컬러별 판매 데이터, 날씨, 프로모션 일정을 학습.
  * *예: "다음 주 [스트레이트용 핀턱 슬랙스 Short-M] 수요가 140% 폭발할 것으로 예측됨 ➡️ 공장 추가 발주 300벌 자동 추천"*
* **적정 판매가 & 마진 AI 계산기**:
  * 원단가, 공임비, 직진배송 물류비, 마케팅비를 입력하면 **목표 영업이익률(예: 25%)을 보장하는 최적의 정가 및 할인가 자동 산출**.

#### ② RAG 기반 스마트 협업 & 나리지 코파일럿 (RAG Collaboration Assistant)
* **기업 내부 데이터 RAG 연동**:
  * 사내 사규, 유관부서(CFO/CTO/SCM) 히스토리 문서, 카카오스타일 과거 프로모션 결과, 디자인 패턴 스펙북을 AI가 상시 학습.
* **실시간 업무 코파일럿 (Copilot)**:
  * MD가 `@NQNQ_AI`로 물어보면 즉시 내부 데이터를 찾아 답변.
  * *예: "@NQNQ_AI 작년 가을 크롭티 런칭할 때 CFO 승인받은 마케팅 예산 비중이 얼마였지?"* 
  * *AI 답변: "2025년 Q3 기준, 매출 목표의 12%를 마케팅비로 승인받았습니다. [관련 문서 링크]"*

#### ③ Generative AI 기반 마케팅 & 비주얼 스튜디오 (Marketing Automation)
* **체형별 타겟 카피라이팅 자동 생성**:
  * 제품 스펙만 넣으면 Z세대 감성의 [스트레이트 / 웨이브 / 내추럴] 체형별 인스타그램 릴스 대본 및 카카오 알림톡 문구 자동 작성.
* **AI 모델 룩북 시뮬레이션**:
  * 샘플 이미지 1장으로 **[155cm 키작녀 모델 / 168cm 키큰녀 모델]**의 착용 컷을 AI로 생성해 상세페이지 비주얼 자동 세팅.

### 🔄 2. End-to-End 상품 생애주기 워크플로우 (스마트 OS 5단계)

[1. AI 기획/트렌드] ➔ [2. ML 발주/생산] ➔ [3. AI 마케팅 생성] ➔ [4. 유관부서 자동승인] ➔ [5. 판매/RAG 피드백]

| 단계 | 주요 기능 및 AI의 역할 | 유관부서 자동 연동 (@태그) |
| :--- | :--- | :--- |
| **1. 기획** | 지그재그 체형 키워드 분석 ➡️ **AI가 결점 보정 신상품 기획서Draft 생성** | `@박지민(디자이너)` 스펙 검토 요청 |
| **2. 생산** | **ML 기반 적정 수량 예측** ➡️ 공장 견적 및 원가 자동 계산 | `@강수진(회계)` 예산 자동 승인 대기 |
| **3. 마케팅** | AI가 숏폼 대본, 상세페이지 문구, AI 착샷 이미지 자동 생성 | `@최유진(마케터)` 소재 검토 및 바이럴 |
| **4. 입고/판매**| 직진배송 센터 바코드 매핑 ➡️ **지그재그 앱 체형 필터 탭 자동 등록** | `@윤도현(개발)` & `@임재범(물류)` 알림 |
| **5. 피드백** | **RAG 피드백 분석**: "허리가 커요" 리뷰 수집 ➡️ 다음 패턴 개선안 자동 추출 | `@NQNQ_Cell` 전체 주간 리포트 발송 |
