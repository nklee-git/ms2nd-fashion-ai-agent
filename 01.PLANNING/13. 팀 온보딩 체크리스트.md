## 🤖 문서가 너무 많아서 부담되면 (선택)
지금 이 볼트만 15개 이상 문서라, "읽고 올 것" 4개 말고 나머지는 언제 다 보나 싶을 수 있음. PM은 Claude Code(또는 파일 접근 가능한 Claude)를 이렇게 쓰고 있음 — 같은 방식 써도 됨.

- **방법**: clone 받은 이 vault 폴더를 Claude Code로 열고, 그냥 평범한 말로 물어보면 됨
  - "01.PLANNING 폴더 문서들 요약해줘"
  - "내 롤(예: ML) 관련해서 TBD로 남은 게 뭐가 있는지 다 찾아줘"
  - "이 문서랑 저 문서 내용이 서로 안 맞는 부분 있는지 확인해줘"
- **왜 쓸만한가**: 사람이 15개 문서를 눈으로 훑으면 놓치는 걸 Claude는 한 번에 다 열어서 비교함. 실제로 이번 프로젝트에서 [[21. Appservice Core model]]이 피벗 전 구버전 내용(NQNQ를 실제 제품처럼 서술)을 그대로 갖고 있어서 나머지 문서랑 모순되던 걸 이렇게 찾아서 고쳤음
- **주의**: 파일을 직접 고치거나 git 커밋/푸시하는 것 같은 되돌리기 번거로운 작업은 하기 전에 먼저 물어보게 하는 게 안전함 — "이렇게 고치면 될까?"라고 반드시 확인받고 진행
