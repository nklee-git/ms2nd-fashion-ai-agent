## 1. 왜 이 프로젝트인가
1차 프로젝트는 10~14일 안에 주제선정→데이터수집→모델링→대시보드를 전부 새로 해야 하지만, 우리는 이미 브랜드·SKU·재고 등 설계문서 35개 + 기상청/체형 실측 데이터로 검증한 108만 건 주문 데이터를 확보한 상태. 처음부터 구현에 집중할 수 있음.

## 2. 포지셔닝
**"카카오스타일 지그재그가 무신사 스탠다드를 겨냥해 PB 브랜드 NQNQ를 만든다면?"**이라는 가상 시나리오 — 실제로 지그재그가 2023년 PB '페어데일'을 낸 것과 같은 패턴이라 서사적으로도 근거가 있음. **NQNQ는 어디까지나 가상 고객사(데이터를 생성해준 시뮬레이션 브랜드)**이고, 우리가 만드는 제품은 **Fashion AI Agent Appservice**.
> 카카오스타일은 실제로 SAP S/4HANA를 쓰고 있음(확인된 사실). **SAP를 대체하는 게 아니라 그 옆에 붙는 AI 재고 리플레니시먼트(수요계획+발주승인) 포인트 솔루션**으로 포지셔닝함 — ERP 세부분야는 "생산/제조"가 아니라 "재고관리·수요계획·구매". 상세: [[12. Market Research]]
> 최종 앱서비스 이름(브랜드명)은 팀원 합류 후 함께 정할 예정 — 현재는 작업용 프로젝트명 "Fashion AI Agent Appservice"로 통칭.

## 3. 핵심 데모 시나리오
품절위험 SKU를 AI가 예측 → Dataverse에 발주추천 레코드 생성 → Teams Adaptive Card로 승인 요청 → 클릭 한 번으로 발주 확정. **이 흐름이 핵심이며, 모든 롤의 작업은 이 흐름을 완성하는 데 수렴한다.

추가로 "커머스 전 과정을 예측할 수 있다"는 걸 증명하기 위해, **2026-08-20을 "오늘"로 고정**하고 9월 한 달을 예측 → 이미 만들어뒀지만 모델에는 숨긴 9월 held-out 데이터와 대조해 정확도를 라이브로 검증하는 시나리오도 준비 중. ([[16. PPT plan]] 참고)

## 4. MVP 범위
- **Must**: Data Factory(오케스트레이션) + **Databricks(ML/데이터처리 핵심)** 파이프라인, Dataverse 발주추천 테이블 + Security Role 2종(승인자/조회자), Power Automate + Teams Adaptive Card 승인 플로우, React 대시보드(승인이력 + 예측대조 뷰)
- **Should**: Power BI 연동, Excel 리포트 export(1차 자산 재사용)
- **제외 확정**: GenAI 콘텐츠 생성(카피라이팅·룩북 이미지), 부서별 다중 KPI 대시보드, 실제 AppSource 등재, 진짜 상시 스트리밍(Event Hub)

## 5. 아키텍처 & 비용 원칙
Azure 기반이 기본이지만, 비용 문제가 있으면 다른 프로그램도 혼용 가능(과제 요건). **Databricks가 기술 핵심으로 승격됐지만, 상시 유료 컴퓨팅은 여전히 지양**:
- Databricks 클러스터는 소형 구성 + 짧은 자동 종료(15~30분) 필수, 작업 끝나면 직접 종료 확인
- 진짜 상시 스트리밍(Event Hub) 대신 Databricks 짧은 주기 micro-batch로 "준실시간" 구현
- Dataverse·Teams·Power Automate·Power BI는 **Microsoft 365 Developer Program 무료 테넌트**로 확보 (비용 0원)
- 자세한 내용: [[22. Cost Plan]]
