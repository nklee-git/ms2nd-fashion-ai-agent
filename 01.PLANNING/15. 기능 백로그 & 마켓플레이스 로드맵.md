## 원칙
- Tier 0/1은 이번 2주 안에서 판가름남. Tier 2 이하는 이번엔 손대지 않고 백로그로만 남김
- 우선순위 기준: **핵심 데모(예측→승인→발주)에 직접 기여하는가?** 기여 안 하면 Tier 2 이하

---

## Tier 0 — 확정 Must ([[24. 기능명세서 v1]] 기준)
- ML 수요예측(로컬 학습) → Dataverse `ReorderRecommendation` 생성 → Teams Adaptive Card 승인 → 발주 확정
- React 대시보드 2뷰(승인이력·예측대조)
- Security Role 2종(Approver/Viewer)
- 9월 held-out 실측 대조 검증

## Tier 1 — 2주 스트레치 (시간 남으면, 핵심과 직접 연결된 것만)
- **GenAI ① 예측근거 자연어 설명** ([[14. 1차 프로젝트 대비 차별화 아이디어]] 논의 5) — Teams 카드에 붙는 한 줄 설명, 가장 가벼움
- **24절기 리드타임 사전알림** (논의 6) — 기존 Teams 파이프라인 재사용, 트리거만 추가
- **Security Role 확장** (논의 2 절충안) — 화면은 그대로, 재무 조회자 등 롤만 추가해서 다중 이해관계자 경험 흉내

## Tier 2 — 3차 프로젝트 백로그 (이번엔 착수 안 함)
- 대시보드 본격 모듈화 (논의 1, Dataverse 테이블+화면 단위 분리)
- RAG 정책 Q&A 코파일럿 부활 (논의 5-②)
- 반려 사유 자동 제안 (논의 5-③)
- 정기 자동 리포트 push (논의 5-④)
- Power BI 연동, Excel export
- Databricks/PySpark ML 업그레이드
- 부서별 다중 KPI 대시보드 본격화

## Tier 3 — 장기 비전 (실제 마켓플레이스 등재 수준, 여러 프로젝트 사이클 이후)
- **소비자용 스토어프론트(상품상세페이지·홈페이지)** — 가상 SKU로 실제 판매 사이트처럼 목업. 핵심 데모(B2B SCM 승인 루프)와는 직접 관련 없는 별도 작업량이라 이번 스코프엔 포함하지 않음. 필요하면 실제 코딩 대신 Figma/정적 HTML 목업으로 "보여주기식"만 충족하는 방법도 있음
- 실제 Dataverse Virtual Table 정식화, Custom Connector 공식 배포
- Partner Center 등록, 기술 인증, 실제 AppSource 등재
- 실사용자 대상 파일럿
