## 진행 히스토리 요약
- 브랜드 기획(SKU, 재고정책, 매출/재무, 조직, 시즌 캘린더 등) 및 데이터 모델링(엔터티/ERD) 완료
- 실제 공개데이터(기상청 기온, 사이즈코리아 신장분포)로 가상데이터 조건화, 108만 건 주문 데이터 생성(SKU 530개, 인기도 티어 롱테일 구조)
- 2차 프로젝트 스코프 확정: ML 수요예측·자동발주 승인 루프를 핵심 데모로 채택, GenAI 마케팅 콘텐츠 생성은 스코프 제외
- 포지셔닝 확정: "Dynamics 365 위에 얹는 패션 버티컬 AI SCM 애드온" — 경쟁사(HauteLogic/K3/Prodware) 대비 "성장 초기 PB 브랜드" 세그먼트 공략
- 아키텍처 확정: Dataverse 단일 저장소, 로컬 ML 학습 기본안, M365 Developer Program 무료 테넌트 활용
- 기능명세서 v1, 팀 온보딩 체크리스트, 팀 공유용 요약 자료 작성
- 발표 컨셉을 외부 MS 판매사원 세일즈 피치에서 사내 NQNQ 개발자→경영진 인프라 도입 제안으로 전환
- 학교 공식 2차 프로젝트 일정 수신 — 실제 날짜(팀확정 9/2·시작 9/11·발표 9/29)로 전 문서 동기화, Dataverse 학습공백 확인 후 시도하기로 결정(SharePoint 폴백 마감선 설정)
