## 🎯 규모 결정 배경
- 타겟(Z세대/사회초년생 여성)이 겹치는 **무신사 스탠다드 우먼**을 성장 벤치마크로 참고.
- 무신사 스탠다드 우먼: 초기 SKU 증가율 100%대(최근 1년 129%), 매출 성장률 초기 76~100%대 → 안정기 41%대로 감속하는 S커브.
- NQNQ는 이보다 **완만한 성장 곡선**을 목표로 설정 (초기부터 과도한 확장 대신 체형 맞춤 품질에 집중).

## ✅ 데이터 반영 완료 (v4, 2026.08)
[[02. Project WBS & Roadmap]] Phase 13에서 트렌드캡슐 5종을 실제 가상데이터에 반영 완료 (SKU 141 + 102 = 243개). 이후 **매출 목표(Y3 1,000억) 대비 SKU가 너무 적어 SKU당 평균 판매량이 비현실적(연 7,600개/SKU)이었던 문제**를 발견 → 디자인 라인업을 확장해 **베이직 428 + 트렌드캡슐 102 = 530 SKU**로 재조정 ([[21. Core Product Categories]], [[22. SKU & Option Code System]] 갱신). 인기도 티어(HERO/STEADY/NICHE) 도입으로 롱테일 구조 구현, 실측 검증 결과 HERO 7,740개/STEADY 2,546개/NICHE 858개(연간)로 설계 비율과 거의 일치. Y3 FW 캡슐(2026.09 예정)은 아직 미출시라 다음 라운드 반영 대상.

## 🧭 카테고리 확장 우선순위
