## 🔢 SKU 코드 체계
형식: `[브랜드]-[카테고리]-[체형/톤코드]-[일련번호]-[사이즈]-[컬러]`

예시:
- `NQ-TOP-STR-001-M-BLK` (스트레이트전용 스퀘어V넥 기본티, M, 블랙)
- `NQ-PNT-5LT-001-S-BLK` (5-Length 슬랙스, Short, 블랙)
- `NQ-CLR-WRM-001-M-CRM` (퍼스널컬러 웜톤 베이직, M, 크림)

| 자리 | 의미 | 값 목록 |
| --- | --- | --- |
| 브랜드 | 고정값 | NQ |
| 카테고리 | 대분류 | TOP / PNT(PANTS) / CLR(COLOR 베이직 라인) / OUT / ACC / DRS |
| 체형/톤코드 | 카테고리별 세분류 | TOP: STR(스트레이트)·WAV(웨이브)·NAT(내추럴)<br>PANTS: 5LT(5-Length 슬랙스)·PLT(핀턱 와이드)<br>COLOR: WRM(웜)·COOL(쿨)·MUT(뮤트) |
| 일련번호 | 스타일 고유번호 | 001~999 |
| 사이즈 | 카테고리별 사이즈표 | 아래 참고 |
| 컬러 | 컬러 코드 | 아래 참고 |

## 🏷️ 라인 타입 (2026.08 추가)
[[21. Core Product Categories]]의 트렌드 캡슐 도입에 따라 스타일마다 라인 타입을 구분한다 (SKU 코드 자체는 안 바뀌고, PRODUCT 엔터티의 별도 속성으로 관리 — [[71. Entity Definitions & Data Dictionary]] 참고).

| 라인 타입 | 설명 | 운영 방식 |
| --- | --- | --- |
| 베이직(BASIC) | 상시 판매, 브랜드 핵심 정체성 | 시즌 제한 없이 지속 판매 |
| 트렌드캡슐(TREND) | 시즌 트렌드 반영, 한정 판매 | 1~2시즌 후 단종 또는 베이직 승격 |

## 📦 시즌1 SKU 규모 (2026.08 확장 반영)
> ⚠️ 2026.08 개정: 매출 목표(Y3 1,000억)에 비해 SKU 수가 지나치게 적어 SKU당 평균 판매량이 비현실적으로 높았던 문제를 발견 (평균 연 7,600개/SKU). 카테고리는 유지하되 **디자인 수를 늘리고 인기도 티어(HERO/STEADY/NICHE)를 도입**해 롱테일 구조로 재설계함.

## 🏷️ 인기도 티어 (2026.08 추가) — 롱테일 반영
디자인마다 판매 가중치를 다르게 부여해, 모든 SKU가 균등하게 잘 팔리는 비현실적 구조 대신 **몇 개 히트작이 대부분을 이끄는 롱테일**을 만든다.

| 티어 | 가중치 | 의미 |
| --- | --- | --- |
| HERO | 3.0x | 카테고리 대표 스테디셀러 (예: 스퀘어라인 기본티) |
| STEADY | 1.0x | 꾸준히 팔리는 보급형 디자인 |
| NICHE | 0.3x | 소량 판매, 취향 세분화용 디자인 |

**검증 결과**(실데이터, [[02. Project WBS & Roadmap]]): HERO 평균 7,740개/년 · STEADY 2,546개 · NICHE 858개 — 설계 비율(3:1:0.3=10:3.3:1)과 거의 일치.
