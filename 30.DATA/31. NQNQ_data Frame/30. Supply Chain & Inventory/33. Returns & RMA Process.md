## 🎪 정책 방향: 오프라인 쇼룸 연계 "관대한 반품/교환"
NQNQ는 "인생핏을 찾을 때까지"라는 브랜드 약속을 지키기 위해, 업계 평균(7~14일)보다 넉넉한 반품/교환 정책을 운영합니다. 향후 오프라인 팝업스토어(쇼룸)에서 핏을 직접 확인할 수 있게 되면, 쇼룸 체험 고객에게는 더 우선적인 프로세스를 제공합니다.

| 항목 | 정책 |
| --- | --- |
| 반품/교환 기간 | 배송완료 후 **30일** (업계 평균 대비 2~4배) |
| 사이즈 교환 횟수 | **무제한** (반품기간 내, 같은 스타일 내 사이즈 변경) |
| 반품 배송비 | 단순변심 포함 **무료** (직진배송 반품 픽업) |
| 착용 허용 범위 | 실내 착용감 확인 허용, 택 제거해도 가능 (세탁·오염·향수 흔적은 제외) |

## 🔀 채널별 처리 방식 차이 (2026.08 개정)
쇼룸이 실제로 운영되기 시작하면서 온라인/오프라인의 반품·교환 처리 방식을 구분합니다.

| 구분 | 온라인(지그재그) | 오프라인(쇼룸) |
| --- | --- | --- |
| 처리 방식 | 택배 접수 → 검수 → 처리 | 현장 즉시 확인 → 즉시 처리 |
| SLA | 검수 완료 후 3일 이내 | 당일 처리 (매장 방문 시 즉시) |
| 주요 반품 사유 | R01~R04 위주 | R05(쇼룸 체험 연계) 비중 높음 |
| 교환:환불 비율 | 60:40 | 80:20 (현장 교환 유도) |

## 🔁 반품/교환 프로세스
1. 앱에서 반품/교환 신청 + 사유 선택
2. 직진배송 무료 픽업 (신청 후 1~2일 내)
3. 물류센터 입고 → 검수 (착용 흔적 vs 오염/훼손 판정)
4. 재입고 판정 및 재고 상태 갱신 ([[OBSIDIAN/2026_MS_DATASCHOOL/20.PROJECT/22.MS_2nd_Project/01.MS_2nd_Project_Team/30.DATA/31. NQNQ_data Frame/30. Supply Chain & Inventory/32. Inventory Policy]]의 반품대기재고 → 가용재고 전환)
5. 환불/교환 처리 (검수 완료 후 3일 이내)
