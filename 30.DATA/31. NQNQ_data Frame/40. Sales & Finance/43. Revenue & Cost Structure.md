## 💰 매출 인식 기준
- 매출 인식 시점: **구매확정 시점** (교환/반품 기간 30일 종료 후 — [[33. Returns & RMA Process]] 참고, 관대한 반품정책 특성상 배송완료가 아닌 구매확정 기준이 안전)
- 취소·환불 처리 기준일: 반품 검수 완료 후 3일 이내

## 🧮 원가 구조 (정가 대비 비율, 목표안)
정가 = (원단비 + 공임비 + 물류비 + 마케팅비 + 채널수수료) ÷ (1 - 목표영업이익률)

| 항목 | 비율 |
| --- | --- |
| 원단비 | 25% |
| 공임비 | 15% |
| 직진배송 물류비 | 8% |
| 마케팅비 | 12% |
| 채널 수수료(지그재그) | 15% ([[42. Channel & Settlement Terms]] 참고) |
| **목표 영업이익률** | **25%** |
| 합계 | 100% |

> 무신사 전체(플랫폼+PB 혼합) 영업이익률이 약 10.8%인 것과 비교하면 NQNQ의 25% 목표는 공격적인 편입니다. PB 단독 직접 제조·판매 구조라 마진이 더 높을 수 있다는 가정이지만, 실데이터 확보 후 하향 조정 여지를 열어둘 것 ([[46. Musinsa Standard Benchmark Reference]] 참고).
