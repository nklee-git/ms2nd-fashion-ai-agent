# 시나리오 비교

- `nqnq.db` — **베이스 시나리오**: 전 분기 매출 목표 99~104% 달성
- `nqnq_scenario_miss.db` — **미달 시나리오**: 공급망 이슈로 일부 분기 목표 미달
  - 2024.12~2025.02 (Y1 FW): 목표 30억 → 실제 24.7억 (82%) — 물류 파트너 온보딩 지연
  - 2025.12~2026.02 (Y2 FW): 목표 120억 → 실제 113.0억 (94%) — 원단 수급 이슈
  - 2026.06~08.09 (Y3 여름): 목표 167.4억 → 실제 157.0억 (94%) — 공장 케파 초과
  - 트렌드캡슐 반영 후에도 미달 패턴은 유지됨

두 DB 모두 스키마 동일 (models.py), 매출 시나리오만 다름.

## 트렌드캡슐 라인 (두 시나리오 공통 반영)
21. Core Product Categories에 정의된 5개 캡슐(Y3 FW 제외) 모두 SKU로 생성됨.
- PRODUCT.line_type = 'BASIC' | 'TREND' 로 구분
- 캡슐은 자동 재발주 대상에서 제외(소량 한정 운영) → 시즌 종료 전 조기 품절되는 경우多
- 판매 종료 후 status='단종' 자동 반영
